# BMP Image Processor

## Описание

**BMP Image Processor** — это консольное приложение для работы с BMP-изображениями. Программа позволяет загружать BMP-файлы, отображать их в текстовом виде, рисовать линии и кресты на изображении, а также сохранять измененные изображения в новый файл.

Программа поддерживает только BMP-файлы с глубиной цвета **24 бита** и **32 бита**. Другие форматы не поддерживаются.

---

## Возможности

- **Чтение BMP-файлов**: Загружает BMP-изображения с глубиной цвета 24 или 32 бита.
- **Отображение изображения**: Выводит изображение в консоль в виде символов:
  - Пробел (``) для белых пикселей.
  - Решетка (`#`) для всех остальных пикселей.
- **Рисование линий**: Позволяет рисовать прямые линии на изображении.
- **Рисование креста**: Рисует крест, соединяя противоположные углы изображения.
- **Сохранение изображения**: Сохраняет измененное изображение в новый BMP-файл.

---

## Требования

- **Компилятор**: Поддержка стандарта C++20.
- **CMake**: Минимальная версия 3.10.
- **Операционная система**: Linux (В приоритете), Windows (проект настроен для работы в Visual Studio Code).

## Установка и сборка

1. **Клонируйте репозиторий**:

   ```bash
   git clone https://github.com/Joraslav/bmpIO.git
   cd Effective-Mobile
2. **Соберите проект с помощью CMake**:

   ```bash
   mkdir build
   cd build
   cmake ..
   cmake --build .
3. **Запустите программу**:

   ```bash
   ./bmpIO

## Использование

1. При запуске программа запросит имя входного BMP-файла:

   ```bash
   Enter input BMP file name:
   ```

   Укажите путь к BMP-файлу с глубиной цвета 24 или 32 бита.
2. Программа отобразит исходное изображение в консоли.
3. Затем программа нарисует крест на изображении и отобразит его в консоли.
4. Программа запросит имя выходного BMP-файла:

   ```bash
   Enter output BMP file name:
   ```

   Укажите путь к новому BMP-файлу, в который будет сохранено измененное изображение.
5. Измененное изображение будет сохранено в указанный файл.

## Ограничения

- Поддерживаются только BMP-файлы с глубиной цвета 24 бита и 32 бита.
- Программа может рисовать только:
- - Прямые линии.
- - Кресты (диагональные линии, соединяющие противоположные углы изображения).
- Изображения с другими форматами или глубиной цвета вызовут ошибку.
